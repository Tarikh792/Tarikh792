## Engineering Principles

- **Understand the fundamentals.** I want to know what a library or framework does under the hood so I can reason about its behavior when something breaks.
- **Break problems into parts.** I separate a problem into smaller pieces that I can implement and test independently.
- **Build for reliability.** I pay attention to correctness and keep the code readable enough to revisit and improve.
- **Learn through implementation.** I turn concepts into working software and use debugging and feedback to guide the next revision.
